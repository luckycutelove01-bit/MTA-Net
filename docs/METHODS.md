## Computational Conventions

For each sample, the loss is `0.6*CDF_L1 + 0.3*interval_L1 + 0.1*(1-cosine)`; the sample weight is `1 + 0.6*H(y)/log(5)`. The mini-batch objective is the mean of weighted sample losses. Validation/test loss is aggregated by sample count so a shorter final batch has the appropriate weight. Checkpoint selection uses validation χ² first and validation MAE for ties; test metrics do not select checkpoints.

The default training batch size is 8. A singleton tail is rebalanced into two non-singleton batches so all 145 training IDs participate in each epoch. Data-set memberships are not regenerated by model seeds. Validation and test preprocessing is deterministic.

The five predicted grain-size fractions are proportions in [0,1]. Metric normalization ranges use the measured labels of the evaluated subset. Five-run summaries use sample standard deviation.

## Explicit Implementation Settings

The code keeps the prediction head shown in Figure 2: 512 → 512 → 256 → 5, with BatchNorm/ReLU/dropout after the first two linear layers. The texture projection uses 944 → 32 → 128 for Stage2, gamma starts at 0.1, and CBAM uses reduction 16 and spatial kernel 7. Current architecture sizes can be obtained from `get_model_info()` or by summing model parameters.

The plain ResNet34 reference and all module-bearing ResNet34 ablations use the same Figure 2 head: 512 → 512 → 256 → 5, with BatchNorm, ReLU and dropout (0.3/0.2) after the first two linear layers. The head is constructed by the shared `build_prediction_head()` function in `Utils/MTA_Net.py`. The same plain ResNet34 reference is used in the comparison, ablation and profile families. Ablations switch only texture modulation and/or CBAM. All models return logits; the shared loss and evaluation functions apply softmax. The encoding, radius and insertion-stage comparisons each share the same head within their family.

The LBP comparison neighbourhoods use the existing 8-point circular, horizontal and vertical layouts. Standard LBP uses radius 1; multiscale variants average radii {1,2}. Circular-rotation canonicalization precedes uniform lookup for the rotation-invariant variant. The common 59-bin layout keeps the feature dimension at 944. These settings are stored with experiment checkpoints.
